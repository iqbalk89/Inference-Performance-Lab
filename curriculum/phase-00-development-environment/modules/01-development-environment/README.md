# Module 01 — Development Environment

**Status:** Complete

**Type:** Learn and build

## Learning Objectives

Explain why an inference engineering workflow uses:

- Git and GitHub
- Python virtual environments
- Docker and Docker Compose
- VS Code and its Python/container extensions
- CUDA, NVIDIA drivers, and PyTorch
- Hugging Face model repositories and metadata

Identify which work can run on the Intel Mac and which requires remote NVIDIA
hardware.

## Minimum Resources

The original Phase 0 used introductory product documentation and short
overviews. For a rebuild, use only:

1. [Git: What is version control?](https://git-scm.com/book/en/v2/Getting-Started-About-Version-Control)
2. [Python virtual environments](https://docs.python.org/3/tutorial/venv.html)
3. [Docker overview](https://docs.docker.com/get-started/docker-overview/)
4. [PyTorch introduction](https://pytorch.org/tutorials/beginner/basics/intro.html)
5. [Hugging Face Hub documentation](https://huggingface.co/docs/hub/index)

Read for purpose and vocabulary, not mastery.
