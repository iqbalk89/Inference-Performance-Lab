    Python for a C++/C# programmer
    • Indentation replaces braces and defines a block.
    • A colon starts a function, loop, or conditional block.
    • def declares a function; parameter and return types are optional.
    • for x in items is similar to a range-based for or foreach loop.
    • len(x) is analogous to size() or Count.
    • raise ValueError(...) is analogous to throwing an argument-related exception.
    • None is Python's no-value object, similar in purpose to null.
