Tensor explorer

Station 3

Matrix microscope

Select any green output cell. The corresponding row of X and column of W will be highlighted. Every output cell is a row–column dot product.

X · [3 tokens, 2 input features]

W · [2 input, 4 output features]

Y = XW · [3 tokens, 4 output features]

The selected cell depends on all products in its dot product. Other output cells do not depend on this selected output cell and expose parallel work.

Station 4

Finite GPU waves

A program can describe more logical tiles than hardware can run at once. Change the work quantity and teaching slots.

Boundary: a tile is not a CUDA core, and a slot is not a complete model of an SM. This station demonstrates finite scheduling capacity and waves only.
Station 5

Attention: scores, mask, and value mixing

Select the query row being updated. Q/K dot products create scores. The causal mask makes future positions contribute zero. Remaining weights mix V rows.

Stage A — Q × Kᵀ creates the complete score matrix

Rows of Q are destination/query positions. Columns of Kᵀ are source/key positions. One score cell is the dot product of one Q row and one Kᵀ column.
